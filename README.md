Payroll Data Warehouse & BI Analysis Project📌 

Опис проєкту
Цей проєкт присвячений розробці та впровадженню сховища даних (Data Warehouse) та системи бізнес-аналітики (BI) для автоматизації аналізу нарахувань заробітної плати та обліку робочого часу працівників. Система побудована на базі технологічного стеку Microsoft SQL Server.🛠 Технологічний стекDatabase Engine: MS SQL Server (Сховище даних Payroll DW).SSIS (Integration Services): ETL-процеси завантаження даних (опціонально).SSAS (Analysis Services): Багатовимірний OLAP-куб.SSRS (Reporting Services): Побудова інтерактивної звітності та дашбордів.Мови запитів: T-SQL, MDX (MultiDimensional eXpressions).🏗 

Структура проєкту
Побудова OLAP-куба (SSAS)В межах проєкту розроблено куб Payroll DW, який включає:Таблиці фактів: Fact Accruals (Нарахування), Fact Work Time (Робочий час).Виміри:Dim Employees — дані про персонал (включаючи ієрархії та складені ключі).Dim Date — часова ієрархія (Рік -> Квартал -> Місяць -> День).Dim Departments — організаційна структура.Dim Positions, Dim Activity.2. Реалізація MDX-обчислень (Calculated Members)Впроваджено 5+ типів складних розрахунків:Time Intelligence: Накопичувальний підсумок (YTD) та порівняння з минулим роком (PY, YoY Growth).Формула YTD: $$AGGREGATE(YTD([Dim Date].[Hierarchy].CurrentMember), [Measures].[Amount])$$Ranking: Визначення Топ-N працівників за сумою нарахувань.Moving Averages: Ковзне середнє за останні 3 місяці.Business Metrics: Середня годинна ставка (Avg Hourly Rate). Ключові показники ефективності (KPI)Налаштовано KPI Accruals Performance для візуального моніторингу виплат:Status: Світлофорні індикатори (Зелений/Жовтий/Червоний).Trend: Стрілки, що вказують на динаміку порівняно з попереднім періодом.
Оптимізація (Performance Tuning)Aggregations: Налаштовано попередні розрахунки для пришвидшення запитів на 30%.Partitions: Таблиці фактів розділені на секції за роками для роботи з великими обсягами даних (1.5 млн+ записів).📊 Візуалізація та звітність (SSRS)Реалізовано 5 типів аналітичних звітів:Table Report: Детальні дані про працівників з групуванням за відділами та підсумками.Matrix Report: Перехресна таблиця нарахувань у розрізі років та департаментів.Chart Report: Візуалізація структури виплат (Pie Chart), динаміки (Line Chart) та порівняння (Column Chart).Dashboard: Зведений звіт з використанням Gauges, Sparklines та KPI-індикаторів.Drill-down Report: Інтерактивна таблиця з можливістю розгортання ієрархії від відділу до конкретного працівника.Інтерактивність та параметриЗвіти підтримують:Множинний вибір (Multi-select) відділів.Залежні параметри (Cascading).Фільтрацію за періодами (Date Range).🚀
